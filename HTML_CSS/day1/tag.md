# HTML 기본 문법 및 주요 태그 정리
## 0. HTML 자동 완성 (Emmet)
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    
</body>
</html>
```
* VS Code 등 주요 에디터에서는 HTML 파일 생성 후 빈 문서에서 `!`를 입력하고 `Enter` 또는 `Tab`키를 누르면 HTML5 기본 문서 구조가 자동으로 생성된다.

## 1. HTML 기본 문서 구조 및 선언

```html
<!DOCTYPE html>
```

* **`<!DOCTYPE html>`**: 작성할 문서가 HTML5 사양임을 브라우저에 선언하는 태그이다.

```html
<html lang="en">
```

* **`<html>`**: HTML 문서의 최상위(Root) 요소이다. `lang="en"` 속성은 해당 문서의 기본 언어가 영어임을 명시한다.

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
```

* **`<head>`**: 화면에 대한 부가 정보(메타데이터)를 담는 공간이다. 직접적인 데이터가 아니며, `<body>` 영역을 설명하는 데이터 역할을 한다.
* **`<title>`**: 웹 페이지의 제목을 지정하며, 브라우저 탭에 표시된다.
* **`<meta charset="UTF-8">`**: 문자 인코딩을 UTF-8로 설정하여 한글 깨짐을 방지한다.
* **`<meta name="viewport" content="width=device-width, initial-scale=1.0">`**: 기기의 크기(화면 너비)에 맞추어 레이아웃이 자동 조정되도록 설정한다.



```html
<body>
    <!-- 실제 화면 콘텐츠 -->
</body>
```

* **`<body>`**: 웹 페이지의 실제 본문 화면에 나타나는 모든 요소를 포함한다.

## 2. HTML 텍스트 처리 및 기본 특징

* **줄바꿈 및 공백 특징**:
* 기본적으로 HTML은 태그를 기준으로 모든 것을 수행한다. 따라서 코드 상에서 줄바꿈을 아무리 많이 해도 브라우저 화면에는 반영되지 않는다.
* 줄바꿈을 표현하려면 `<p>` 태그로 문단을 나누거나 `<br>` 태그를 사용해야 한다.



### 텍스트 및 구분선 태그

* **`<h1>` ~ `<h6>**`: 헤딩(Heading) 태그로 제목이나 강조할 텍스트를 나타낸다. `<h1>`이 가장 크고 중요하며, `<h6>`까지 존재한다.
* **`<p>`**: 문단(Paragraph)을 나타내는 태그이다. 태그별로 자동 구분되어 문단 단위의 줄바꿈을 처리할 때 사용한다.
* **`<br>`**: Break의 약자로, 브레이크를 걸어 줄바꿈을 수행한다.
* `\n`과 동일하게 작동한다.
* 닫는 태그 없이 단일로 사용하는 태그이다.
* *참고*: 일반적으로 여백이나 공백 조절을 목적으로 `<br>`을 남발하지는 않는다.


* **`<hr>`**: Horizontal Line의 약자로, 화면에 가로선을 그어주는 태그이다.
* 닫는 태그가 없는 단일 태그이다.
* *참고*: 세로선을 그어주는 태그는 따로 존재하지 않는다.

## 3. 핵심 식별자 속성 (id / class)

모든 HTML 태그에는 `id`와 `class` 속성을 부여할 수 있다.

* **`id`**: Identity의 약자로, 특정 태그를 독자적으로 식별할 때 사용한다.
* **중복 불가**: 한 페이지 내에서 유일해야 한다.


* **`class`**: 여러 개의 태그를 그룹으로 묶어줄 때 사용한다.
* **중복 가능 (권장)**: 스타일(가운데 정렬, 볼드체, 폰트 등)을 지정해두고 여러 요소에 재사용한다.
* 하나의 태그가 여러 개의 클래스를 동시에 가질 수도 있다. (예: `class="btn primary bold"`)

## 4. 폼 및 입력 태그 (`<form>`, `<input>`)

### `<form>` 태그

사용자 입력 데이터를 서버로 전송할 때 사용한다.

* **`action`**: 입력한 값이 전달될 서버 주소를 지정한다. (예: `action="https://google.com/search"`)
* **`method`**: 데이터 전송 방식을 지정한다. (기본값: `GET`)
* **`GET`**: 데이터를 URL 쿼리 파라미터로 보낼 때 사용한다. (무엇을 쓸지 모르면 대부분 GET 방식이다.)
* **`POST`**: 회원가입, 로그인 등 데이터를 서버 내부로 보낼 때 사용한다.
* *참고*: `<form>` 태그 내에서는 `GET`과 `POST` 방식만 지정 가능하며, 다른 HTTP 메서드는 JavaScript를 활용한다.



### `<label>` 태그

* 입력 항목의 이름/라벨을 표시한다.
* **`for` 속성**: 식별을 위해 작성하며, 연결할 `<input>`의 `id` 값을 지정해 어떤 입력 창을 위한 라벨인지 구별한다.

### `<input>` 태그

* 사용자로부터 데이터를 입력받는 태그이다.
* **`name`**: 서버로 전송될 때 쿼리 파라미터의 키(Key) 이름이 된다.
* **`id`**: 태그(컴포넌트) 자체에 붙여주는 식별 이름이다.
* **`placeholder`**: 입력란에 작성 힌트 문구를 보여준다.
* **`type` 주요 종류**:
* `text`: 일반 텍스트 입력받기
* `password`: 비밀번호 입력용으로, 입력값이 비활성화(마스킹) 처리된다.
* `email`: 이메일 형식에 맞는 입력을 검증해 준다.
* `search`: 검색어 입력용으로, 입력받은 데이터를 x 버튼으로 지울 수 있는 기능이 제공된다.



### `<button>` 태그

* 폼 내에서 작성된 데이터를 제출(`submit`)하거나 이벤트를 실행시킨다.

## 5. 미디어 및 링크 태그 (`<img>`, `<a>`)

### `<img>` 태그

이미지를 화면에 출력하는 태그로, 닫는 태그가 없는 독립(단일) 태그이다.

* **`src`**: Source의 약자로 이미지의 근원, 원천, 출처(URL 또는 로컬 경로)를 지정한다.
* **`alt`**: Alternative text의 약자로, 사진 경로가 잘못되거나 깨졌을 때 대신 출력할 대체 텍스트를 지정한다.
* **`width`**: 이미지의 너비를 지정한다.
* *참고*: 로컬 이미지 경로(예: `./image.png`)를 불러올 경우, 응답할 서버가 없으므로 쿼리 파라미터를 사용할 수 없다.

### `<a>` 태그

* Anchor의 약자로, 외부 주소나 다른 페이지로 이동하는 하이퍼링크를 생성한다.
* **`href`**: 이동할 목표 주소(URL)를 지정한다.

---

## 6. 리스트 태그 (`<ul>`, `<ol>`, `<li>`)

여러 개의 데이터를 목록 형태로 출력할 때 사용한다.

### `<ul>` 태그 (Unordered List)

* 순서가 없는 리스트로, 순서를 신경 쓰지 않는 항목들을 나열할 때 사용한다. (기본 불릿 기호)

### `<ol>` 태그 (Ordered List)

* 순서가 있는 리스트로, 항목 앞에 숫자가 자동으로 붙는다.
* **`type` 속성**: 순서 표기 형식을 지정한다.
* `a`: 소문자 알파벳
* `A`: 대문자 알파벳
* `i` / `I`: 로마자 숫자


* **`start` 속성**: 순서가 시작되는 시작값을 지정한다.

### `<li>` 태그 (List Item)

* `<ul>` 및 `<ol>` 내부에 위치하며, 각 목록 항목을 나타낸다.

---

## 7. 레이아웃 및 시멘틱 태그

### `<div>` 태그 (Division)

* 구역을 나눌 때 쓰는 범용 블록 태그이다.
* *참고*: 의도적으로 `<div>` 사용을 줄이고, 가독성과 의미 전달을 위해 **시멘틱(Semantic) 태그**로 구성을 노력해야 한다.

### 시멘틱(Semantic) 태그

* **`<header>`**: 페이지나 섹션의 상단/헤더 영역
* **`<main>`**: 페이지의 주요 본문 콘텐츠 영역
* **`<footer>`**: 페이지 하단/푸터 영역 (저작권, 연락처 등)

---

## 8. 표 태그 (`<table>`)

데이터를 표 형태로 나타낼 때 사용한다.

* **`<table>`**: 표 전체를 감싸는 태그이다.
* `border`: 경계선 굵기를 지정하는 옛 속성이며, 현재는 CSS로 처리한다.


* **`<thead>`**: 테이블의 헤더 영역을 묶어준다.
* **`<tbody>`**: 테이블의 본문 데이터 영역을 묶어준다.
* **`<tr>`**: Table Row의 약자로, 표의 한 행을 생성한다.
* **`<th>`**: Table Head의 약자로, `<tr>`에 들어가는 제목 셀 요소이다.
* **`<td>`**: Table Data cell의 약자로, `<tr>`에 들어가는 일반 데이터 셀 요소이다.
