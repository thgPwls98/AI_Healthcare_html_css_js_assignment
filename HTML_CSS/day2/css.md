## 1. CSS(Cascading Style Sheets)란?

* CSS : HTML 문서의 스타일과 레이아웃(디자인)을 정의하는 언어
    - HTML이 웹페이지의 뼈대(구조)를 만든다면, CSS는 그 뼈대에 옷(디자인)을 입히는 역할을 한다. 
    - HTML 구조와 CSS 스타일을 분리하여 작성하는 것이 웹 표준에 부합한다.

## 2. CSS 적용 방식

### ① Inline CSS (인라인 스타일)

HTML 태그 내부의 `style` 속성을 이용하여 직접 스타일을 적용하는 방식이다.

* **특징:** 우선순위가 매우 높지만, 재사용성이 떨어지고 코드가 지저분해진다.

```
<p style="color: blue; font-size: 16px;">인라인 스타일 예시</p>
```

### ② Internal CSS (내부 스타일 시트)

HTML 문서 내의 `<head>` 태그 안에 `<style>` 태그를 만들어 스타일을 정의하는 방식이다.

* **특징:** 해당 HTML 파일 안에서만 스타일이 적용된다.

```
<head>
  <style>
    #contents {
      text-align: center;
    }
  </style>
</head>
```

### ③ External CSS (외부 스타일 시트)

별도의 `.css` 파일을 작성하고, HTML에서 `<link>` 태그로 불러와 사용하는 방식이다. **(가장 권장됨)**

* **특징:** 유지보수가 쉬우며 여러 HTML 파일에서 동일한 스타일을 재사용할 수 있다.

```
<head>
  <link rel="stylesheet" href="style.css">
</head>
```

## 3. CSS Selector (선택자) 및 우선순위

선택자(Selector)는 **스타일을 적용할 HTML 태그를 고르는 조건**이다.

### 3.1 기본 선택자 종류

1. **전체 선택자 (`*`)**: 페이지 내 모든 요소를 선택한다.

2. **태그 선택자 (`div`, `header` 등)**: 특정 태그명을 가진 모든 요소를 선택한다.

3. **클래스 선택자 (`.class`)**: 특정 클래스명을 가진 요소를 선택하며, 마침표(`.`)를 붙인다.

4. **아이디 선택자 (`#id`)**: 특정 ID를 가진 유일한 요소를 선택하며, 샵(`#`)을 붙인다.

### 3.2 자식 및 자손 선택자

* **자식 선택자 (`>`)**: 바로 아래에 있는 직접적인 자식 태그만 선택한다. (예: `plate > apple`)

* **자손 선택자 (`공백`)**: 아래에 포함된 모든 후손 태그를 선택한다. (예: `plate apple`)

> 💡 자손 선택자(공백)가 적용 범위가 더 넓고 포괄적이어서 실제 개발 시 많이 사용된다.

### 3.3 선택자 명시도 (우선순위)

여러 스타일 규칙이 충돌할 때 적용되는 우선순위 순서이다.

$$
\text{Inline Style} > \text{ID Selector (\#)} > \text{Class Selector (.)} > \text{Tag Selector} > \text{Universal Selector (*)}
$$

* `!important` (최상위) > `inline style` > `#id` > `.class` > `tag` > `*`

* 전체 선택자(`*`)가 우선순위가 가장 낮다.

## 4. `style` 속성

HTML 태그에 직접 `style="속성: 값;"` 형태로 디자인을 지정할 때 사용하는 속성이다.

* 인라인 스타일(Inline Style)을 작성할 때 활용된다.

* 특정 요소에만 빠르게 스타일을 적용하거나 테스트할 때 유용하지만, 남발하면 코드 가독성을 해친다.

## 5. Text 관련 주요 속성

* **`font-size`**: 글자 크기를 지정한다. (`px`, `rem`, `em`, `x-large`, `x-small` 등)

* **`font-weight`**: 글자 두께를 지정한다. (`normal`, `bold`, `100` \~ `900`)

* **`text-align`**: 텍스트 정렬 방식을 지정한다. (`left`, `center`, `right`, `justify`)

## 6. CSS 박스 모델 (Box Model)

모든 HTML 요소는 상자(Box) 모양의 영역을 가진다.

```
+-----------------------------------+
|              margin               |  <- 바깥쪽 여백
|  +-----------------------------+  |
|  |           border            |  |  <- 테두리
|  |  +-----------------------+  |  |
|  |  |        padding        |  |  |  <- 안쪽 여백
|  |  |  +-----------------+  |  |  |
|  |  |  |     content     |  |  |  |  <- 실제 내용 (width x height)
|  |  |  +-----------------+  |  |  |
|  |  +-----------------------+  |  |
|  +-----------------------------+  |
+-----------------------------------+
```

### 박스 모델 구성 요소

* **Content**: 텍스트나 이미지가 들어가는 실제 내용 영역이다.

* **`width` / `height`**: 요소의 가로 및 세로 크기를 지정한다.

* **Padding**: 테두리(Border)와 Content 사이의 **안쪽 여백**이다.

* **Border**: 요소의 **테두리 두께 및 스타일**이다.

* **Margin**: 다른 요소와의 간격을 조절하는 **바깥쪽 여백**이다.

### `box-sizing` 속성

* **`content-box` (기본값)**: `width`와 `height`가 Content 영역만을 의미한다. Padding이나 Border가 들어가면 전체 크기가 커진다.

* **`border-box`**: `width`와 `height`에 Padding과 Border 두께까지 포함된다. 레이아웃을 계산할 때 훨씬 직관적이고 편리하다.
```
{
  box-sizing: border-box; /* 전체 요소의 크기 계산을 편리하게 함 */
}
```

## 7. 요소의 Display 성질 (Block vs Inline)

HTML 요소는 기본적으로 Block 성질 또는 Inline 성질을 갖는다.

| **구분** | **Block-level 요소** | **Inline 요소** | 
| **줄바꿈** | 자동으로 줄바꿈이 일어난다. (가로 한 줄을 전체 차지) | 줄바꿈 없이 옆으로 나란히 배치된다. | 
| **영역 크기** | 부모 요소의 가로 폭 전체(100%)를 차지한다. | 콘텐츠(텍스트/이미지) 크기만큼만 영역을 차지한다. | 
| **대표 태그** | `div`, `p`, `header`, `main`, `footer`, `h1`\~`h6` 등 | `span`, `strong`, `a`, `img` 등 | 
| **크기 지정** | `width`, `height`, `margin`, `padding` 모두 적용 가능하다. | `width`, `height` 지정이 불가하며 상하 margin이 제한적이다. | 

## 8. Emmet 단축키 (자동 완성 기능)

VS Code 등에서 HTML 코드를 빠르게 작성할 때 사용하는 단축키 패턴이다.

* **`div.box` + `Enter`**: 클래스명이 `box`인 `div` 태그를 생성한다.

  ```
  <div class="box"></div>
  ```

* **`p*3` + `Enter`**: `p` 태그를 연속으로 3개 생성한다.

  ```
  <p></p>
  <p></p>
  <p></p>
  ```

* **`lorem` / `lorem30` + `Enter`**: 30개의 단어로 구성된 테스트용 무의미 텍스트(Dummy Text)를 자동 생성한다. (숫자를 변경하여 단어 수 조절 가능)
